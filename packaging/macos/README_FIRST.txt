Playlist Sync — 처음 실행 방법 / First launch

1. "Playlist Sync" 아이콘을 옆의 Applications 폴더로 끌어 넣습니다.
2. Applications 폴더에서 Playlist Sync 를 더블클릭합니다.
3. "확인할 수 없습니다" 경고가 뜨면 [완료]를 누르고
   시스템 설정 → 개인정보 보호 및 보안 → 아래쪽의 [그래도 열기] 를 누른 뒤 암호를 입력합니다. (처음 한 번만)
   이 앱은 무료 배포라 Apple 유료 서명을 받지 않았습니다.
4. 폴더 접근을 묻는 창이 뜨면 [허용] 을 누릅니다.
5. Serato DJ Pro 와 rekordbox 를 종료한 상태에서 동기화합니다.

1. Drag "Playlist Sync" onto the Applications folder.
2. Double-click Playlist Sync in Applications.
3. If macOS says it cannot verify the app, click Done, then open
   System Settings → Privacy & Security → "Open Anyway" and enter your password (first launch only).
4. Allow folder access when asked.
5. Close Serato DJ Pro and rekordbox before syncing.
